How the hybrid works

  1. Routine checks stay on-device. The photo and notes go to Gemini Nano inside Chrome through Firebase AI Logic. Nothing is uploaded, nothing is billed, and it works offline.
  2. The fallback is automatic. On browsers without an on-device model, the same request runs against cloud Gemini — same prompt, same structured result, labelled as cloud.
  3. Depth is a deliberate escalation. Severe or uncertain cases get a full agronomist report from the cloud model, only when the scout asks for it.

Built for the #BuildHybridAI 2026 hackathon. On-device inference requires desktop Chrome 139+ with the Prompt API flag enabled. Cloud fallback needs a Firebase project with AI Logic enabled — see SETUP.md.
